# Changelog

All notable changes to RepoVitals are documented here.

## 1.1.0 - 2026-08-26

### Added

- Shareable audit links that preserve the selected GitHub username.
- Downloadable Markdown reports with scores, pin candidates, recommendations, and evidence.
- Downloadable JSON snapshots for further analysis.
- Tests for deterministic portable-report generation.

## 1.0.0 - 2026-08-26

### Added

- Public GitHub portfolio scoring and six-repository showcase ranking.
- Evidence ledger, prioritized recommendations, caching, and responsive interface.
- Automated tests, CI, and GitHub Pages deployment.
